# Media Assets

Optional files used by the invitation:

- `background.mp4`: muted looping background video.
- `background-music.mp3`: user-initiated background music.

Recommended export settings:

- Video: MP4/H.264, 720p or lower, 5-8 seconds, muted, 2-4 MB if possible.
- Audio: MP3, low volume master, 60-120 seconds loop, make sure you own the rights.

Mobile browsers block autoplaying audio, so music starts only after the sound
button is tapped.
